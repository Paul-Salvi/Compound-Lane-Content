# 01-text/ — Platform copy for fall-conversion-deadline (Roth Limits 2026 / Reel #24)

This directory holds the YouTube / Instagram / Twitter copy that ships with the **Fall is the Home Stretch for Roth Conversions** reel.

## Source numbers (locked, trace to `01-content/fall-conversion-deadline.json`)

- ~100 days — Sept 22 to Dec 31
- 12/31 — annual conversion deadline
- $50,000 — example conversion amount
- 22% — current tax bracket
- 32% — future tax bracket projection
- $11,000 — tax savings on $50K conversion (22% vs 32%)

## Files (filled in this order)

1. **keywords.txt** — keyword research (Stage 1)
2. **youtube.txt** — title + description + tags + Category/Type for Studio
3. **instagram.txt** — hook + caption + alt text
4. **twitter.txt** — main post + reply-link note
5. **youtube-problems.txt** — (Stage 3, post-render) timecoded Q&A
6. **spanish-subs.srt** — (Stage 4, post-render) Spanish SRT for YouTube Studio
