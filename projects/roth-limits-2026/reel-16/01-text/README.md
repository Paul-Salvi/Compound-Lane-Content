# 01-text/ — Platform copy for roth-conversion-3-numbers (Roth Limits 2026 / Reel #16)

This directory holds the YouTube / Instagram / Twitter copy that ships with the **Roth conversion: 3 numbers that decide** reel.

## Source numbers (locked, trace to `01-content/roth-conversion-3-numbers.json`)

- 24% — example marginal bracket
- 32% — next bracket up (the "do not cross" threshold)
- $50,000 — example conversion size
- $12,000 — example federal tax on the conversion
- 73 — RMD age
- IRC §408(d)(2) — conversion statute

## Files (filled in this order)

1. **keywords.txt** — keyword research (Stage 1)
2. **youtube.txt** — title + description + tags + Category/Type for Studio
3. **instagram.txt** — hook + caption + alt text
4. **twitter.txt** — main post + reply-link note
5. **youtube-problems.txt** — (Stage 3, post-render) timecoded Q&A
6. **spanish-subs.srt** — (Stage 4, post-render) Spanish SRT for YouTube Studio
