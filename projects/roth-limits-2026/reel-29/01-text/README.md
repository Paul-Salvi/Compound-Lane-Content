# 01-text/ — Platform copy for roth-at-60 (Roth Limits 2026 / Reel #29)

This directory holds the YouTube / Instagram / Twitter copy that ships with the **Roth at 60: Age 59½ + 5 Years** reel.

## Source numbers (locked, trace to `01-content/roth-at-60.md`)

- 59½ — age threshold for penalty-free Roth earnings (IRC §72(t))
- 5 years — Roth qualified-distribution holding period (IRC §408A(d)(2))
- $50,000 — example conversion amount
- $5,000 — 10% penalty on $50K example
- 10% — IRC §72(t) early-withdrawal penalty rate

1. **keywords.txt** — keyword research (Stage 1)

4. **twitter.txt** — main post + reply-link note
5. **youtube-problems.txt** — (Stage 3, post-render) timecoded Q&A
