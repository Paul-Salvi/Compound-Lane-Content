# 01-text/ — Platform copy for early-withdrawal-penalty (Roth Limits 2026 / Reel #21)

This directory holds the YouTube / Instagram / Twitter copy that ships with the **10% Early-Withdrawal Penalty (and 5 Exceptions)** reel.

## Source numbers (locked, trace to `01-content/early-withdrawal-penalty.json`)

- 10% — early-withdrawal penalty on earnings
- 59½ — age before which the penalty applies
- 5 — IRS-recognized exceptions
- $10,000 — first-time home purchase lifetime cap
- $5,000 — birth or adoption per-child cap
- 7.5% — AGI threshold for medical expense exception
