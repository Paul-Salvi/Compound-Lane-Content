# 01-text/ — Platform copy for roth-prorata-90k (Roth Limits 2026 / Reel #10)

This directory holds the YouTube / Instagram / Twitter copy that ships with the **The pro-rata rule (with a $90,000 example)** reel, ready to paste into each platform at upload time.

## Source numbers (locked, trace to `01-content/roth-prorata-90k.json`)

- $90,000 — pre-tax traditional IRA balance (the example case)
- $7,000 — after-tax backdoor contribution
- 90/97 — the pro-rata ratio (90% pre-tax, 7% after-tax)
- $6,495 — taxable portion of the $7,000 conversion under pro-rata

1. **keywords.txt** — keyword research (Stage 1)

5. **youtube-problems.txt** — (Stage 3, post-render) timecoded Q&A
