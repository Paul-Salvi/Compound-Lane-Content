## Canvas

- Frame: 1080×1920
- Page: 1080×1920, revealed word-by-word across the 93s timeline

- Coordinate space: x grows right, y grows down. The pen is positioned by setting its `transform: translate(x, y)` where (x, y) is the **nib** location.

## Animation primitives

All beats share the same primitives (mirrors DCA `04-video/index.html` lines 854–902):

- **Move** — `gsap.to(pen, {x, y, duration, ease: "none"})` for per-word positioning, snap-to-target on each new word. Long moves use a short 60ms duration so the pen appears to "hop" to the next word.
- **Word reveal** — `gsap.fromTo(span, {opacity: 0, y: 6, rotation: rot}, {opacity: 1, y: 0, rotation: 0, duration: 0.42, ease: "power2.out"})` for each `.w` span.
- **Num-blob pop** — `gsap.fromTo(el, {opacity: 0, scale: 0.8, rotation: -4}, {opacity: 1, scale: 1, rotation: 0, duration: 0.4, ease: "back.out(1.5)"})`.
- **SVG stroke draw** — `gsap.fromTo(path, {strokeDasharray: len, strokeDashoffset: len}, {strokeDashoffset: 0, duration: 0.5, ease: "power1.inOut"})` for arrow paths and underline rules.
- **Arrowhead pop** — `gsap.fromTo(polygon, {opacity: 0, scale: 0.4, transformOrigin: "center"}, {opacity: 1, scale: 1, duration: 0.3, ease: "back.out(1.5)"})`.

The whole timeline is built once at load, registered on `window.__timelines["one-thousand-decision-tree-video"]`, paused. HyperFrames drives `seek` to scrub; GSAP handles deterministic playback.

## Sound schedule (per-element action → SFX)

The inline script auto-builds `window.__soundSchedule` while iterating `schedule.forEach(buildGroup)`:

- `.w` (word) → "write" (throttled to ≥1.5s between writes in the same group)
- `path` (SVG stroke: rule, arrow) → "draw"
- `.hl` (yellow highlighter) → "highlight"
- `.compare-card` / `.warning-box` / `.flow-node` → "cardReveal" (one per concept, first occurrence only)
- `.ledger-row` → "appear"

SFX are routed through `scripts/sound/profile-paper-explainer.mjs` → resolver → `scribble.mp3` / `chalk.mp3` / `highlight.mp3` / `card-place.mp3` / `pop.mp3`. Triggers fire in `window.__soundSchedule` order; per-row `seed` gives deterministic playback-rate jitter so repeated sounds don't sound machine-gun.
