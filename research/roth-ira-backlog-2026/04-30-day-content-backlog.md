## 7. Pre-flight checklist (apply before any reel is built)

For every reel, the build pass must confirm:

1. **Word count 75–100** (per `docs/pacing-rules-v1.md`).
2. **Hook ≤ 12 words, lands by 2s.**
3. **Forbidden openers avoided** ("hey guys," "today I'm going to," "in this video," "welcome back").
4. **Peak number lives in segment 3** (quantify_opportunity_cost, 20–30s).
5. **Mid-video reset at ~20s** (a component change, not a long static frame).
6. **No component type repeats** within one reel.
7. **Silence gaps ≤ 0.4s** (per Paul / VibeVoice pacing).
8. **CTA is a single ask** (save / follow / share / comment / "next one" — not two).
9. **Critical text not in bottom 25% or right edge** (caption-safe zone).
10. **Every number in script traces** to a source in `01-seo-keyword-research.md` or to a cited IRS / IRS-Pub / Schwab / Vanguard / Fidelity / Forbes / Kitces / IRC section.
11. **No "you should" tax advice** — "here's the rule" only.
12. **No ticker / brokerage / fund recommendation** — provider-agnostic.
13. **No promised returns** — "the historical real return of US large-cap is ~7%" only.
