# Taste — Coding, Tooling & Workflow Preferences
- Prefers to provide source content as a local file rather than having the assistant web-fetch from URLs; explicitly instructs "dont webfetch" when content is already saved locally. Confidence: 0.9
- Wants comprehensive documentation that captures both required actions AND explicit don'ts/pitfalls, so repeatable workflows can be executed at "lightning speed" on future tasks. Confidence: 0.85
- Values investing in upfront documentation/guides to optimize speed and consistency across recurring/repeated creative tasks. Confidence: 0.8
- Prefers a **single source of truth** for production knowledge (e.g. a top-level `GUIDE.md`) that agent instruction files (`AGENTS.md`/`CLAUDE.md`) **cross-reference** rather than duplicate inline; keeps agent context slim but always pointing at the canonical, up-to-date workflow. Confidence: 0.75
- Expects agent context files to be **kept in sync** with newly captured production guides — when a guide is created/updated, `AGENTS.md`/`CLAUDE.md` should be edited to carry the same learnings (commands, pitfalls, audio setup), and new projects should get their own copies — explicitly requested with "also update the guide and agent" after a task, so future sub-agent runs inherit the latest knowledge; the user then verifies the **root-level** docs were updated ("Does the agent and guid updated at root?"), treating root `AGENTS.md`/`GUIDE.md` as the canonical knowledge store. Confidence: 0.9
- Wants to provide all required project inputs **upfront via a structured fill-in-the-blank checklist** (Source, Type, Length, Format, Voice/Speed, Brand, Fonts, Logo, Hook, Key data, CTA, Don'ts) rather than through conversational Q&A; this minimizes back-and-forth so the assistant can work at "lightning speed." Confidence: 0.85
- Prefers portrait (1080×1920) format for short-form social video, explicitly requesting "format portrait" rather than the default landscape. Confidence: 0.85
- Requests videos under 60 seconds by default, indicating a preference for short-form, high-impact content that fits social media consumption patterns. Confidence: 0.75
- Open to sub-agent parallelization — explicitly suggests "you can also create sub agents to make work fast and efficient and accurate," indicating a preference for splitting independent tasks across parallel execution paths. Confidence: 0.8
- Wants project learnings captured iteratively into the workflow guide after each completed project — explicitly instructs "capture what you learn new so you dont make mistake again," reflecting a preference for continuous improvement through documented lessons learned. Confidence: 0.8
- When updating shared documentation across multiple copies, prefers adapting inserted content to each file's existing formatting conventions (markdown table rows in tabular sections, plain bullets in list-style files) rather than force-pasting identical blocks everywhere. Confidence: 0.7
- Prefers verifying actual file state (read/grep) before retrying edits that previously failed or landed incorrectly, then applying precise targeted fixes instead of blindly re-running the failed commands. Confidence: 0.7
- Treats reference/sample images as **style guides only** — when restyling an existing video from a sample on a different topic, keeps all content, beat timings, duration, and voiceover untouched and changes visuals exclusively; never imports the sample's text/content into the target. Confidence: 0.75
- Does NOT want videos rendered automatically after changes — rendering is explicitly excluded unless requested; validation happens through the check command instead, with results reported back and any follow-up (e.g., version bumps) left for the user to approve. Confidence: 0.65
- Expects compositions to be validated with `npm run check` (HyperFrames) after every edit, fixing ALL errors and layout-overflow warnings before declaring the task complete. Confidence: 0.7
- Compound Lane Visual System (per GUIDE.md section 11) assigns fonts by role: **Fraunces** (serif) for headlines/titles/section heads, **IBM Plex Mono** (mono, with `tabular-nums`) for numbers/stats/inputs, **Inter** (sans) for body text/subtitles/labels/descriptions — applied via CSS variables (`--font-headline`, `--font-mono`, `--font-body`) with sensible font-stack fallbacks. These fonts are imported from Google Fonts and applied to specific selectors/classes rather than globally. Confidence: 0.85
- HyperFrames voiceover generation uses local Kokoro TTS via the version-pinned CLI (`npx --yes hyperframes@0.8.10 tts "<script>" --voice am_michael --speed 1.25 -o audio/voiceover.wav`); on Windows this requires setting `$env:HYPERFRAMES_PYTHON` to the Python 3.11 executable first. Confidence: 0.7
- After generating TTS, re-times the composition to the measured audio rather than the planned duration: verifies actual VO length (e.g., ffprobe), sets the `<audio data-duration>` to match exactly, shifts frame boundaries/GSAP timestamps so each visual lands while its narration line is spoken, and trims total composition length if speech comes in shorter than planned. Confidence: 0.75
- New HyperFrames video projects are scaffolded as complete self-contained folders mirroring the proven sibling project's exact file set — `package.json` (pinned-version npm scripts), `hyperframes.json`, `meta.json`, `BRIEF.md`/`STORYBOARD.md`/`SCRIPT.md`/`frame.md` planning docs, `assets/` logo copy, `capture/extracted/` source extractions, and a monolithic GSAP-timeline `index.html`. Confidence: 0.7
- Expects background music (BGM) to be part of a finished reel — after a complete voiceover-only video was delivered without music, immediately requested "Add a suitable BGM"; delegates track/mood selection to the assistant ("suitable") rather than supplying specific audio, so treat BGM selection as a standard deliverable component of future video projects. Confidence: 0.7
- Before generating BGM for a reel, expects the assistant to consult the project's audio skills/reference docs (hyperframes-audio, media-use `bgm.md`) and propose a topic-appropriate mood prompt rather than guessing — explicitly asked "check the BGM music skill, and what prompt should be added for this reel". Confidence: 0.7

Confidence: 0.7
- BGM bed wiring: a non-clip `<audio id="bgm" src="audio/bgm.wav">` element on its own track at low volume (`data-volume` ≈ 0.12), generated slightly longer than the composition (e.g. a 40s bed for a 37s reel) so there is no silent tail, and ducked under the voiceover via the hyperframes-audio carve script (the classifier keys on "bgm"/"music" in the id/filename). Confidence: 0.7

Confidence: 0.6
